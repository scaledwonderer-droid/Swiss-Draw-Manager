# Swiss Draw Manager

BO3（2本先取）の対戦会を、ブラウザだけで運営できる日本語のSwiss Draw管理アプリです。サーバー、アカウント、外部API、ビルド処理は不要です。PCとスマートフォンに対応しています。

## 主な機能

- 任意人数のプレイヤー登録と名前変更
- Swiss Draw方式の対戦自動生成
- 全体の組み合わせを探索した強い再戦回避
- `W-W`、`W-L-W`、`L-W-W`を区別するBO3ゲーム入力
- マッチポイント、ゲーム差、対戦相手成績による順位計算
- W-L-W傾向を同条件時のペアリング補助として利用
- 奇数人数の公平なBYE割り当て
- 途中ドロップと参加復帰
- 過去結果の修正と全成績の再計算
- LocalStorageへの自動保存
- JSONバックアップのエクスポート／インポート
- 大会終了後の最終順位、履歴、個人統計の閲覧

## 使い方

1. 大会名、参加者、総ラウンド数、ポイント設定を入力します。
2. 「大会開始」を押すとRound 1の対戦が生成されます。
3. 各対戦でGame 1から勝者を順番に選びます。2勝した時点で入力が終了します。
4. 表示されたスコアと試合経過を確認し、「この結果で確定」を押します。
5. 全対戦を入力したら「ラウンド確定」、続けて「次ラウンド生成」を押します。
6. 指定ラウンド数が終わると大会終了となり、最終順位が表示されます。

結果を誤入力した場合は、確定済みカードまたは「履歴」から修正できます。後続ラウンド作成後の修正では、既存ペアリングと成績が食い違う可能性を警告します。

## Swiss Drawとペアリング方式

Swiss Drawは、勝ち抜き式で脱落させず、成績の近い参加者同士を各ラウンドで組み合わせる方式です。

このアプリは単純な上から順の組み合わせではなく、18人以下では可能な完全マッチングを動的計画法で比較します。19人以上では候補を広く保持するビーム探索を利用します。組み合わせ全体を評価するため、一つの再戦を避けた結果、後続カードが再戦だらけになる局所的な問題を抑えます。

評価要素は次の順序を基本とします。

1. 再戦を強く回避
2. マッチポイント差を小さくする
3. W-L-W傾向の近い相手を優先
4. 現在順位の差を小さくする

再戦とポイント差には大きな重みを設定し、W-L-W傾向だけを理由に大きな実力差のカードは作りません。どうしても再戦が必要な場合は、対戦画面に警告を表示します。

## BO3と試合経過

すべての対戦は2本先取です。2勝した時点で終了します。

- `W-W`：2-0勝利
- `W-L-W`：第1ゲーム勝利、第2ゲーム敗北、第3ゲーム勝利
- `L-W-W`：第1ゲーム敗北、第2・第3ゲーム勝利

勝者側と敗者側の試合経過は、それぞれの視点で自動保存されます。たとえば勝者が `W-L-W` なら敗者は `L-W-L` です。

## 順位計算

順位は次の優先順位で決まります。

1. マッチポイント
2. ゲーム差（ゲーム勝数 − ゲーム敗数）
3. 対戦相手成績
4. マッチ勝利数
5. 初期登録順（安定した最終決定方法）

「対戦相手成績」は、実際に対戦した全相手の現在マッチポイントの合計です。一般的なBuchholz方式に近い値です。BYEは対戦相手がいないため、この合計には含みません。

W-L-W回数は順位には影響しません。ポイント、再戦条件などが同等な候補の間で、次の相手を選ぶ補助指標にだけ使います。これは試合経過の統計であり、プレイヤーの意図や心理を推定するものではありません。

## BYE

参加中プレイヤーが奇数の場合、1名をBYEにします。BYE回数が少ない人を最優先し、その中でポイントと順位が低い人を優先します。設定したBYEポイントを自動付与し、ゲーム勝敗には加算しません。

## ドロップ

大会中は参加者を削除せず、「プレイヤー」画面でドロップします。過去の戦績と対戦履歴は保持され、次ラウンドからペアリング対象外になります。「参加へ戻す」で復帰できますが、生成済みの現在ラウンドには自動挿入されません。

## 保存とJSONバックアップ

状態は操作ごとにLocalStorageへ自動保存され、同じブラウザでページを開き直すと復元されます。ただし、ブラウザデータを消去すると失われます。

「設定」から大会全体をJSONファイルに保存できます。別端末では同じ画面からJSONをインポートしてください。読み込み時にバージョン、プレイヤーID、ラウンド、BO3結果を検証し、不正なデータは適用しません。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの `index.html`、`style.css`、`app.js`、`README.md`、`LICENSE`、`.nojekyll` をリポジトリ直下へアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** のSourceで **Deploy from a branch** を選びます。
5. `main` ブランチと `/ (root)` を選び、保存します。
6. 表示されたURLへアクセスすると利用できます。

データは利用者それぞれのブラウザ内にのみ保存されます。公開リポジトリやGitHub Pagesへ大会データが送信されることはありません。

## ローカルで確認する

`index.html` を直接開いて利用できます。簡易Webサーバーを使う場合は、このフォルダで次を実行し、表示されたローカルURLを開きます。

```bash
python -m http.server 8000
```
